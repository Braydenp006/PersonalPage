About the server

No cloud host. This site is served by an HP Z420 running FreeBSD, with one jail per service and bhyve Linux VMs for the apps that only ship for Docker. Besides this site it runs my own Git server (Forgejo, mirroring my GitHub), my email, a Minecraft server, Valheim and Sons of the Forest servers I start when they're needed, and willbot, my local AI assistant. Behind my VPN it also keeps my passwords (Vaultwarden), files and calendar (Nextcloud), photos (Immich), databases (PostgreSQL) and monitoring (Prometheus). [TODO: why you host what you do]
