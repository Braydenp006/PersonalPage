What my server records

The site runs on my own server at home. Like almost every web server, it keeps a standard access log of each request: your IP address, the time, the page or file asked for, and your browser's user-agent.

  • I use these logs only to keep the server secure and to count visits and traffic for the live stats on How this site runs. Those stats are totals only and never show IPs or anything that identifies you.

Other services the site uses

Some parts of the site load from other companies, which means your browser connects to them and they can see your IP address. They have their own privacy policies:

  • Cloudflare sits in front of my server to protect it and speed it up. Every visit passes through it.
  • Google Fonts serves some of the typefaces.
  • jsDelivr serves the code libraries for the 3D models and the map.
  • pygame-web serves the runtime that lets the Python games in the arcade play in your browser.
  • OpenFreeMap serves the map tiles on the About page.

Links to GitHub, LinkedIn and the client sites I've built take you to those sites, and their own policies apply there.
